> [!IMPORTANT]
> **Это референс, а не рабочий сервис.** Проект показывает, как может выглядеть и вести себя калькулятор подписок. Кнопка «Оформить подписки» ничего не оплачивает и ни к чему не подключена, а цены и скидки выдуманы и не совпадают с настоящими тарифами. Названия и логотипы сервисов принадлежат их владельцам и использованы только для демонстрации.

## Запуск

Ничего устанавливать не нужно. Склонируйте репозиторий и откройте `index.html` в браузере: скрипты подключены обычными тегами `<script>`, поэтому страница работает и по `file://`.

```bash
git clone https://github.com/maks3592/subscription-calculator.git
cd subscription-calculator
```

Нужен локальный сервер, например чтобы открыть страницу с телефона в той же сети:

```bash
python -m http.server 8000
# http://localhost:8000
```

Онлайн-версия: https://maks3592.github.io/subscription-calculator/

## Расчёт цены

У каждого сервиса есть цена за один месяц. Стоимость за выбранный срок считается так:

```text
без скидки = цена за месяц × число месяцев
итого      = без скидки × (1 − скидка)
```

| Срок | Скидка |
|:---:|:---:|
| 1 месяц | 0 % |
| 3 месяца | 5 % |
| 6 месяцев | 10 % |
| 12 месяцев | 20 % |

Пример: Netflix на 12 месяцев стоит 799 ₽ × 12 = 9 588 ₽ без скидки и 7 670 ₽ со скидкой 20 %, то есть 639 ₽ в месяц.

## Как изменить каталог

Данные лежат в [`js/data.js`](js/data.js). Чтобы добавить сервис, допишите строку в массив `SERVICES`:

```js
{id:'myservice', name:'Мой сервис', cat:'Сервисы', price:299, icon:si('github','FFFFFF')},
```

| Поле | Значение |
|---|---|
| `id` | Уникальный идентификатор, по нему корзина хранится в `localStorage` |
| `name` | Название на карточке |
| `cat` | Категория. Новая категория появится в фильтре сама |
| `price` | Условная цена за месяц в рублях |
| `includes` | Необязательно. Список пар `['Название', 'домен.ру']`: показывается как блок «Входит в подписку» |
| `icon` | `si(slug, hex)` берёт логотип с [Simple Icons](https://simpleicons.org), `fav(domain)` берёт фавикон сайта (для него добавьте `isFav:1`) |

Скидки меняются в объекте `DISCOUNT`, доступные сроки — в массиве `TERMS`. Каждому сроку из `TERMS` должна соответствовать скидка в `DISCOUNT`.

## Данные в браузере

Всё хранится локально, на сервер ничего не уходит.

| Ключ `localStorage` | Содержимое |
|---|---|
| `subcalc` | Корзина: идентификатор сервиса и выбранный срок |

Сбросить корзину можно кнопкой «Очистить» или в консоли:

```js
localStorage.removeItem('subcalc'); location.reload();
```

## Структура проекта

```text
.
├── index.html          # разметка страницы
├── css/
│   └── style.css       # стили, переменные цвета, анимации, адаптивность
├── js/
│   ├── data.js         # сроки, скидки, каталог сервисов
│   ├── state.js        # состояние, localStorage, расчёт цены
│   ├── ui.js           # анимированный счётчик, уведомления, запасная иконка
│   ├── catalog.js      # карточки, поиск и фильтр по категориям
│   ├── cart.js         # корзина и итоговые суммы
│   └── main.js         # запуск
├── docs/
│   └── screenshot.png
├── README.md
└── LICENSE
```

Модулей ES и сборщика нет: это обычные скрипты, которые делят общую область видимости. Поэтому порядок подключения в `index.html` важен: `data.js` → `state.js` → `ui.js` → `catalog.js` → `cart.js` → `main.js`.

## Совместимость

Нужен актуальный Chrome, Edge, Firefox или Safari: используются CSS-переменные, `grid`, `mask-image` и `backdrop-filter`. Без `backdrop-filter` страница работает, только без эффекта стекла. Шрифт Inter и иконки загружаются из сети, без неё подставляются системный шрифт и буквы.
