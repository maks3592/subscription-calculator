## Быстрый старт

**Онлайн:** https://maks3592.github.io/subscription-calculator/

**Локально.** Ничего устанавливать не нужно: склонируйте репозиторий и откройте `index.html` в браузере. Скрипты подключены обычными тегами `<script>`, поэтому калькулятор работает и по `file://`, без сервера.

```bash
git clone https://github.com/maks3592/subscription-calculator.git
cd subscription-calculator
```

Если нужен локальный сервер, например чтобы проверить страницу на телефоне в одной сети с компьютером:

```bash
python -m http.server 8000
# откройте http://localhost:8000
```

## Возможности

| | |
|---|---|
| **Каталог** | 23 сервиса в четырёх категориях: кино и ТВ, музыка, игры, прочие сервисы |
| **Срок на карточке** | Переключатель 1 / 3 / 6 / 12 месяцев, цена в месяц и размер скидки пересчитываются сразу |
| **Скидки за срок** | До 20 % за год вперёд, старая цена показывается зачёркнутой |
| **Поиск и фильтры** | Живой поиск по названию и фильтр по категориям с плавным переключателем |
| **Корзина** | Срок можно сменить прямо в корзине, сервис удаляется одним нажатием, есть кнопка «Очистить» |
| **Итог** | Сумма без скидки, выгода и итоговая стоимость с анимированным счётчиком |
| **Сохранение** | Корзина хранится в `localStorage` и не пропадает после перезагрузки |
| **Оформление** | Монохромная тёмная тема, подсветка карточек за курсором, плавные анимации. С `prefers-reduced-motion` анимации отключаются |
| **Адаптивность** | На узких экранах корзина уходит под каталог, появляется плавающая кнопка «Корзина» |

## Как считается цена

Каждый сервис имеет базовую цену за один месяц. Стоимость за выбранный срок:

```text
без скидки = цена за месяц × число месяцев
итого      = без скидки × (1 − скидка)
```

| Срок | Скидка |
|:---:|:---:|
| 1 месяц | 0 % |
| 3 месяца | 5 % |
| 6 месяцев | 10 % |
| 12 месяцев | 20 % |

Например, Netflix за 12 месяцев: 799 ₽ × 12 = 9 588 ₽ без скидки, со скидкой 20 % выходит 7 670 ₽ (639 ₽ в месяц).

> Цены в каталоге ориентировочные и могут отличаться у самих сервисов. Кнопка «Оформить подписки» ничего не оплачивает, она только показывает итоговую сумму.

## Каталог сервисов

Каталог описан массивом `SERVICES` в [`js/data.js`](js/data.js). Чтобы добавить сервис, достаточно одной строки:

```js
{id:'myservice', name:'Мой сервис', cat:'Сервисы', price:299, icon:si('github','FFFFFF')},
```

| Поле | Значение |
|---|---|
| `id` | Уникальный идентификатор, по нему корзина хранится в `localStorage` |
| `name` | Название на карточке |
| `cat` | Категория. Новая категория появится в фильтрах автоматически |
| `price` | Цена за один месяц в рублях |
| `icon` | Ссылка на иконку: `si(slug, hex)` берёт логотип с [Simple Icons](https://simpleicons.org), `fav(domain)` берёт фавикон сайта. Для фавиконов добавьте `isFav:1` |

Скидки меняются в объекте `DISCOUNT`, доступные сроки — в массиве `TERMS`. Если иконка не загрузилась, вместо неё показывается первая буква названия.

## Данные в браузере

Всё хранится локально в `localStorage`, на сервер ничего не отправляется.

| Ключ | Содержимое |
|---|---|
| `subcalc` | Корзина: идентификатор сервиса и выбранный срок |

Полный сброс:

```js
localStorage.removeItem('subcalc'); location.reload();
```

## Структура проекта

```text
.
├── index.html          # разметка
├── css/
│   └── style.css       # стили, переменные цвета, анимации, адаптивность
├── js/
│   ├── data.js         # сроки, скидки, каталог сервисов
│   ├── state.js        # корзина, localStorage, расчёт цены
│   ├── ui.js           # анимированный счётчик и всплывающие уведомления
│   ├── catalog.js      # карточки, поиск и фильтры по категориям
│   ├── cart.js         # корзина и итоговые суммы
│   └── main.js         # запуск
├── docs/
│   └── screenshot.png
├── README.md
└── LICENSE
```

Модулей ES и сборщика нет: это обычные скрипты, которые подключаются в `index.html` по порядку и делят глобальную область видимости. Благодаря этому страница запускается двойным кликом по файлу. Порядок подключения важен: `data.js` → `state.js` → `ui.js` → `catalog.js` → `cart.js` → `main.js`.

## Совместимость

Нужен актуальный Chrome, Edge, Firefox или Safari: используются CSS-переменные, `backdrop-filter`, `mask-image` и `grid`. Без `backdrop-filter` страница работает, только без эффекта стекла. Шрифт Inter и иконки сервисов загружаются из сети; без интернета подставляются системный шрифт и буквы вместо логотипов.
